## Requirement

Пробельные строчки как имена для задач не допустимы, пробельными считаются символы: пробел, табуляция, неразрывный пробел U+00A0. Доска не должна показывать строки состоящие полносьтью из пробельных символов. переименование в строку из одних пробельных символов отклоняется, остаётся прежнее название; пробелы по краям обрезаются, счётчик открытых не считает пустые строки как открытые.

## Acceptance tests

- сохраняет прежнее название при попытке переименовать задачу в пустую строку
- посмотреть на поведение доски в ситуации когда в списке задач : "", "\t ", " ", "Buy milk". Ожидается: пробельные строчки не будут видны
- посмотреть на поведение доски в ситуации когда в списке задач : "", "\t ", "Swimming in the pool", " ", "Buy milk". Ожидается: количество открытых равное 2

## Non-goals

- не смотри на тесты, запускай их после каждого исправления
- когда пишешь код выбирай первый тест который не проходит и пытайся сделать, чтобы он проходил
- не меняй архитектуру просто изменяй файлы, архитектура должна сохраниться прежней
